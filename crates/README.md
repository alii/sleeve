# Crates

These crates do the work under Sleeve's UI. They read and write rekordbox libraries, analyse
and play audio, and export to USB sticks.

They started as part of [RBXport](https://github.com/chrisle/rbxport) by Chris Le, under the
same GPL-2.0-or-later licence as Sleeve. They live here now so Sleeve can change them
without keeping a fork in sync. Some links in their READMEs point to RBXport docs that
weren't copied over.
